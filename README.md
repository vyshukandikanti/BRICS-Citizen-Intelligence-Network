# BRICS Citizen Intelligence Network (BCIN)

AI-powered Digital Public Infrastructure platform that converts citizen voices into structured infrastructure intelligence for government decision-making.

## Features
- 🎤 Real voice recognition (Telugu, Hindi, English)
- 📸 AI image analysis for issue detection
- 🗺️ Interactive Leaflet map with real district data
- 🔐 Government-protected dashboard
- 📄 PDF report export
- 🔔 Real-time notifications
- 📱 PWA with offline support
- 🌐 3 languages: English, Hindi, Telugu
